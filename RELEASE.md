# Release: Direct ZIP (v1.0.0)

This release provides a ready-to-download ZIP archive that contains the scripts and notes for downloading and packaging the curated handwritten fonts list.

Download the ZIP (auto-generated from the repository's main branch):

- Zip (all files in repository): https://github.com/BoxGlorious/fonts-handwritten/archive/refs/heads/main.zip

What is inside the ZIP

- download-and-zip.sh — Bash script (Linux/macOS/WSL) to download the 30 fonts, generate LICENSES.txt and create fonts-handwritten.zip
- download-fonts.ps1 — PowerShell script (Windows) to do the same
- README.md — Usage and run instructions
- LICENSES.txt — Short license/source notes (generated by the scripts when you run them locally)

Notes & Usage

- The ZIP is the repository snapshot (source code ZIP). It does not contain pre-downloaded font binaries. The scripts inside will fetch the TTF/OTF files from their original hosts when you run them locally.
- For a distributable ZIP that bundles the font binaries, run the included script on your machine or a trusted server to produce "fonts-handwritten.zip" and then upload that artifact where you need it (S3, GitHub Releases as an asset, etc.).

License reminder

Most fonts listed in this repository are sourced from Google Fonts and use the SIL Open Font License (OFL), which permits commercial use. Double-check each font's license if you plan to redistribute fonts with commercial products.
